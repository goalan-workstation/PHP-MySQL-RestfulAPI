2. 資料庫結構（alan_php 資料庫）
───────────────────────────────────────────────────────────────────────────────

  資料表            │ 用途說明
  ──────────────────┼────────────────────────────────────────────────────
  activity          │ 最新消息/活動內容（標題、副標題、描述、圖片、啟用狀態）
  admin             │ 後台管理員帳號（帳號、密碼雜湊、權限 JSON、暱稱、備註）
  album             │ 相簿主檔（標題、封面、圖片 JSON、排序、啟用狀態）
  contact_us        │ 聯絡我們表單訊息（姓名、信箱、標題、內容、備註）
  member            │ 會員資料（姓名、信箱、電話、地址、備註、購物車 JSON）
  member_account    │ 會員帳號系統（user_id、user_pwd 外掛欄位）
  news              │ 最新消息（標題、副標題、描述、圖片、啟用狀態、排序）
  products          │ 產品資料（標題、描述、圖片、庫存、售價、排序）
  shopping_cart     │ 購物車（會員外鍵、購物車 JSON、檢視狀態、結單狀態）
  users             │ 使用者系統（前台使用者帳號）
  web_info          │ 網站基本設定（網站標題、描述、區塊 JSON、橫幅圖片）
  web_style         │ 網站色系設定（style_option 0-4）

  共通欄位慣例：
    id              │ BIGINT UNSIGNED / BIGSERIAL，主鍵
    title           │ TEXT，主標題
    title_2         │ TEXT，副標題
    description     │ TEXT，描述內容
    CHK             │ SMALLINT，啟用/停用狀態（0=停用，1=啟用），CHECK 約束僅允許 0/1
    creat_time      │ TIMESTAMP，建立時間
    updata_time     │ TIMESTAMP，更新時間
    data_sort       │ BIGINT / INT，自訂排序次序

3. 核心檔案功能說明
───────────────────────────────────────────────────────────────────────────────

┌───────────────┐
│ login.php     │ 登入流程
│───────────────│
│ • session_start() 啟動 Session                     │
│ • 已登入者自動跳轉至 dashboard.php                  │
│ • POST 提交帳號、密碼後，依 admin 資料表驗證        │
│ • 支援密碼雜湊（password_hash / password_verify）   │
│ • 若為舊型明文密碼，自動昇級為 bcrypt 雜湊          │
│ • 登入成功建立 Session：admin_id、admin_name、      │
│   admin_nic（暱稱）與 admin_power（權限）            │
│ • CSRF token 由 admin_permissions.php 映射載入      │
│ • 登入失敗顯示錯誤訊息                              │
└───────────────┘

┌───────────────┐
│ logout.php    │ 登出流程
│───────────────│
│ • 清除 $_SESSION 陣列                              │
│ • 刪除 Session Cookie                              │
│ • 銷毀 Session                                     │
│ • 跳轉回 login.php                                  │
└───────────────┘

┌───────────────┐
│ theme.php     │ 全域佈局與主題
│───────────────│

│ • 查詢 web_style.style_option 取得目前主題（0-4）    │
│ • 主題無效時拋出 RuntimeException                    │
│ • 已登入時載入並緩存 admin_nic / admin_name          │
│ • 提供 adminIdentityMarkup() 函式輸出登入者標記       │
│ • 所有後台頁面皆 require_once theme.php              │
└───────────────┘

4. 模組開發模式（list.php + edit.php）
───────────────────────────────────────────────────────────────────────────────

【列表頁 list.php】共同模式
  1. session_start() + 登入檢查（未登入跳 login.php）
  2. require_once theme.php
  3. define PER_PAGE（分頁每頁筆數）
  4. 產生 CSRF token（$_SESSION 暫存）
  5. 參數清洗：page、sort、order、show_all、搜尋 q
  6. POST action 處理：刪除（CSRF 驗證、FOR UPDATE 排他鎖定、事務）
  7. AJAX reorder 處理：拖曳排序 → JSON 回傳
  8. 統計總筆數、計算分頁
  9. 查詢並分頁列表
 10. 輸出 HTML（麵包屑、表格、分頁導航、拖曳排序腳本）

【編輯頁 edit.php】共同模式
  1. 登入檢查 + theme.php
  2. 載入模組專屬 image_storage.php（如有）
  3. 擷取 id（GET/POST），驗證整數
  4. 若 id 存在 → SELECT 取得資料；不存在則 404
  5. 建立 $formValues 表單預設值
  6. POST 處理：
       • CSRF 驗證
       • 表單驗證（標題必填、啟用狀態合法等）
       • 圖片上傳 → stage 暫存 → 壓縮/縮圖
       • 新增：INSERT
       • 編輯：UPDATE（事務 + 舊圖片替換/清理）
  7. 成功跳回 list.php（攜帶 page/sort/order）
  8. 顯示表單（含當前縮圖預覽）


───────────────────────────────────────────────────────────────────────────────
5. 圖片處理機制（image_storage.php / banner_storage.php）
───────────────────────────────────────────────────────────────────────────────

  • 單一模組一個 image_storage.php，定義模組上限與函式
  • 支援格式：JPG / PNG / WebP（最大 5 MB）
  • 大圖自動壓縮（迭代降質直至符合上限）
  • 產生原圖 + 縮圖（_thumb 副檔名）
  • 檔名採用 32 位元 hex 雜湊，防止路徑穿越
  • 上傳先寫入 .stage_ 暫存檔，成功後才 rename 至最終路徑
  • 編輯更換圖片時保留舊圖 backup_，失敗時回滾
  • 儲存成功後清理所有暫存/備份檔


───────────────────────────────────────────────────────────────────────────────
6. 安全性設計
───────────────────────────────────────────────────────────────────────────────

  • 強制類型宣告（declare(strict_types=1)）
  • 所有輸入使用 filter_var / 類型檢查清洗
  • CSRF 保護：bin2hex(random_bytes(32)) + hash_equals()
  • SQL 注入防護：PDO Prepared Statement + bindValue
  • 輸出防 XSS：htmlspecialchars($..., ENT_QUOTES, 'UTF-8')
  • 密碼安全：bcrypt（password_hash）+ password_verify
  • 資料庫排他鎖定：SELECT ... FOR UPDATE + 事務（beginTransaction/commit/rollback）
  • 權限隔離：admin_power 權限清單過濾功能入口
  • 圖片路徑白名單：preg_match 驗證 32 位元 hex 格式
  • 第一筆 admin 帳號受保護（不可刪除）


───────────────────────────────────────────────────────────────────────────────
7. 前端互動特色
───────────────────────────────────────────────────────────────────────────────

  • 拖曳排序（Drag & Drop）：list.php 使用 HTML5 DnD，AJAX POST 更新 data_sort
  • 動態分頁：page 參數、上一頁/下一頁按鈕
  • 多維度排序：狀態（CHK）、更新日期、排序次序
  • 即時搜尋：member/news 等列表支援 q 搜尋參數
  • 5 套 CSS 主題：CSS 變數切換（藍色系、綠色系、紫色系、橘色系、粉紅色系）
  • 無刷新更新：重排序、刪除後 AJAX 重繪表格
